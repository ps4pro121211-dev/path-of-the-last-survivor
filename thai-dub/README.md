# Thai Dub: พากย์ไทยจากซับในเกม (ทดสอบกับ Red Dead Redemption 2)

โปรแกรมจะอ่านซับภาษาอังกฤษบนจอ แปลเป็นภาษาไทย แล้วพูดออกมาด้วยเสียงไทยแบบอัตโนมัติ
**ใช้ได้ฟรีทั้งหมด** ไม่ต้องมีการ์ดจอแรง แต่ต้องต่ออินเทอร์เน็ต

```
อ่านซับบนจอ (Windows OCR) → แปลไทย (Google Translate) → เสียงไทย (Microsoft Edge TTS)
```

---

## 1. ติดตั้ง (ทำครั้งเดียว)

### 1.1 ติดตั้ง Python
1. ดาวน์โหลด **Python 3.12** จาก https://www.python.org/downloads/
2. ตอนติดตั้ง **ต้องติ๊กช่อง `Add python.exe to PATH`** ด้านล่างของหน้าติดตั้ง

### 1.2 เพิ่มภาษาอังกฤษใน Windows (สำหรับ OCR)
ถ้า Windows ของคุณเป็นภาษาไทย ต้องเพิ่มภาษาอังกฤษก่อน เพราะ Windows OCR ใช้ภาษาที่ติดตั้งในเครื่อง
1. ไปที่ `Settings` → `Time & Language` → `Language & region`
2. กด `Add a language` แล้วเลือก **English (United States)**
3. รอให้ติดตั้งเสร็จ ไม่ต้องตั้งเป็นภาษาหลัก

### 1.3 ติดตั้งโปรแกรม
ดับเบิลคลิก **`install.bat`** แล้วรอจนขึ้นว่าติดตั้งเสร็จ

---

## 2. ตั้งค่าในเกม RDR2

| เมนู | ตั้งค่าเป็น | เหตุผล |
|---|---|---|
| Settings → Graphics → **Screen Type** | **Windowed Borderless** | ถ้าเป็น Fullscreen โปรแกรมอาจจับภาพจอได้แค่สีดำ |
| Settings → Display → **Subtitles** | **On** | โปรแกรมต้องอ่านซับ |
| Settings → Language | **English** | ตั้งค่าเริ่มต้นของโปรแกรมไว้สำหรับอ่านซับอังกฤษ |
| Settings → Audio → เสียงพูด (Dialogue) | ลดให้เบาลง (ถ้ามีตัวเลือก) | จะได้ยินเสียงไทยชัดขึ้น |

---

## 3. วิธีใช้
1. เปิดเกม แล้วเล่นไปจนถึงฉากที่มี**ซับขึ้นอยู่บนจอ**
2. ดับเบิลคลิก **`run.bat`**
3. จอจะมืดลงและแสดงภาพหน้าจอเกม ให้**ลากเมาส์ครอบบริเวณที่ซับขึ้น** (ด้านล่างกลางจอ)
   ครอบให้สูงพอสำหรับซับ 2 บรรทัด แต่อย่ากว้างเกินจนครอบส่วนอื่นของหน้าจอเกม (HUD) เข้ามาด้วย
4. กด Alt+Tab กลับเข้าเกม แล้วเล่นตามปกติ เมื่อซับขึ้น โปรแกรมจะพากย์ไทยให้เอง

โปรแกรมจะจำกรอบที่เลือกไว้ ครั้งต่อไปเปิดแล้วใช้ได้เลย

### ปุ่มลัด (กดได้ระหว่างเล่นเกม)
| ปุ่ม | หน้าที่ |
|---|---|
| **F8** | หยุด / เล่นต่อ |
| **F7** | สลับเสียงผู้ชาย ↔ ผู้หญิง |
| **F9** | เลือกกรอบซับใหม่ |
| **F6** | บันทึกภาพดีบัก (ใช้ตอนโปรแกรมอ่านซับไม่ออก) |
| **F10** | ปิดโปรแกรม |

> ถ้าปุ่มลัดใช้ไม่ได้ขณะอยู่ในเกม ให้คลิกขวาที่ `run.bat` แล้วเลือก **Run as administrator**

---

## 4. ปรับแต่ง (ไฟล์ `config.json`)
ไฟล์นี้จะถูกสร้างหลังเปิดโปรแกรมครั้งแรก เปิดแก้ด้วย Notepad ได้ แล้วปิดโปรแกรมและเปิดใหม่เพื่อให้ค่าที่แก้มีผล

| ค่า | ความหมาย | แนะนำ |
|---|---|---|
| `voice` | `th-TH-NiwatNeural` (ชาย) / `th-TH-PremwadeeNeural` (หญิง) | |
| `rate` | ความเร็วเสียงพูด | `"+15%"` ถึง `"+30%"` ช่วยให้พากย์ทันเกม |
| `white_text_threshold` | ความสว่างขั้นต่ำของตัวหนังสือซับ | ถ้าอ่านซับไม่ออกตอนฉากสว่าง (หิมะ ท้องฟ้า) ให้เพิ่มเป็น `200`–`220` |
| `interrupt_on_new_line` | `true` = ซับใหม่ขึ้นมาแล้วตัดเสียงเก่าทิ้ง | ใช้ `true` ถ้ารู้สึกว่าเสียงไทยตามหลังเกมเยอะ |
| `stable_reads` | ต้องอ่านข้อความเดิมได้กี่ครั้งติดกันจึงจะเริ่มพากย์ | ถ้ามีการพากย์ข้อความขยะ ให้เพิ่มเป็น `3` |
| `scan_interval` | อ่านจอทุกกี่วินาที | `0.35` |

---

## 5. แก้ปัญหา

**ขึ้นข้อความ "Python was not found" หรือ "Python is not installed"**
→ ยังไม่ได้ติดตั้ง Python ให้ติดตั้งตามข้อ 1.1 แล้วรัน `install.bat` ใหม่
   ถ้าติดตั้งแล้วยังขึ้นข้อความเดิม ให้ไปที่ `Settings` → `Apps` → `Advanced app settings` → `App execution aliases`
   แล้ว**ปิด** `python.exe` และ `python3.exe` (ตัวที่เขียนว่า App Installer)

**ข้อความในหน้าต่างดำเป็นภาษาอังกฤษ**
→ ตั้งใจให้เป็นแบบนั้น เพราะหน้าต่าง cmd แสดงภาษาไทยเป็นกล่อง ๆ อ่านไม่ออก แต่เสียงพากย์ยังเป็นภาษาไทยตามปกติ

**ไม่พากย์เลย หรืออ่านซับผิด**
→ กด **F6** ตอนที่ซับขึ้นอยู่ แล้วเปิดโฟลเดอร์ `debug` ดูภาพ `_processed.png`
   - **ตัวหนังสือขาดหรือจาง:** ลดค่า `white_text_threshold` ลง (เช่น `150`)
   - **พื้นหลังเป็นจุดดำเต็มภาพ:** เพิ่มค่า `white_text_threshold` (เช่น `210`)
   - **ซับไม่อยู่ในภาพ:** กด **F9** แล้วเลือกกรอบใหม่

**ขึ้นข้อความ "ใช้ Windows OCR ไม่ได้"**
→ ยังไม่ได้เพิ่มภาษาอังกฤษใน Windows (ดูข้อ 1.2) หรือใช้ Python ใหม่กว่า 3.12
   ถ้าแก้แล้วยังไม่ได้ ให้ติดตั้ง Tesseract จาก https://github.com/UB-Mannheim/tesseract/wiki
   แล้วแก้ `config.json` เป็น `"ocr_engine": "tesseract"`

**ภาพที่ใช้เลือกกรอบเป็นสีดำ**
→ เปลี่ยนเกมเป็นโหมด **Windowed Borderless**

**เสียงไทยมาช้า**
→ เป็นข้อจำกัดของระบบนี้ ปกติจะช้ากว่าภาพประมาณ 1–2 วินาที ช่วยได้โดยเพิ่ม `rate` และตั้ง `interrupt_on_new_line` เป็น `true`

## ข้อจำกัด
- คำแปลเป็นสำนวน Google Translate ชื่อคนหรือสำนวนคาวบอยบางคำอาจแปลแปลก ๆ
- ทุกตัวละครใช้เสียงเดียวกัน (สลับเสียงชาย/หญิงได้ด้วย F7)
- ตอนขี่ม้าแล้วตัวละครคุยกันเร็ว ๆ บางประโยคอาจถูกข้าม เพื่อไม่ให้เสียงไทยตามหลังเกมเกินไป
